Generative music: the math behind raga, and a machine that performs it live

A raga is not a scale. It is a grammar and a clock. Both can be handed to a machine. By the end of this session the machine will be two hundred phones, and the room will be the instrument.

A workshop by Ujjwal Agarwal (KALA) · orderofkala.org · raga.fm. Bring a laptop and headphones. Your phone is the last instrument.

program 1Notes from a scale, chosen purely at random

Open the p5.js web editor, make a new sketch, replace everything with this, press play, click the canvas. Headphones on.

// Program 1 · a scale in a key, notes picked purely at random

let sa = 261.63;      // Sa, in hertz. This is C4. Change it to your key.
let scale = [1, 9/8, 5/4, 4/3, 3/2, 5/3, 15/8, 2];   // S R G M P D N S', as ratios to Sa
let names = ['S', 'R', 'G', 'M', 'P', 'D', 'N', "S'"];
let osc, drone, now = '';

function setup() {
  createCanvas(400, 400);
  textAlign(CENTER, CENTER); textSize(120);
  osc = new p5.Oscillator('triangle'); osc.amp(0); osc.start();
  drone = new p5.Oscillator('sawtooth'); drone.freq(sa); drone.amp(0); drone.start();
}

function mousePressed() {
  userStartAudio();          // browsers stay silent until you click
  drone.amp(0.05, 0.5);      // the tanpura: Sa, held forever
}

function draw() {
  background(244, 239, 230);
  if (frameCount % 30 === 0) {               // twice a second...
    let i = floor(random(scale.length));     // ...pick ANY note of the scale. No memory, no grammar.
    osc.freq(sa * scale[i]);
    osc.amp(0.3, 0.02);
    now = names[i];
  }
  if (frameCount % 30 === 22) osc.amp(0, 0.1);
  fill(21); text(now, width / 2, height / 2);
}

Three things to change. Make scale five notes: [1, 9/8, 5/4, 3/2, 5/3, 2] is S R G P D, the notes of Bhupali. Make it slower: % 60. Make the drone louder. Then ask yourself why it still is not Bhupali.

program 2The same scale, with a memory of one note

Now the next note depends on the note before it. That is all a Markov chain is: a table of "from here, go there, this often". The table below is Bhupali's climb and descent with its signature phrase counted three times.

// Program 2 · a Markov chain: each note is chosen from the note before it

let sa = 261.63;
let ratio = { S:1, R:9/8, G:5/4, P:3/2, D:5/3, "S'":2, "D.":5/6 };    // D. is the Dha below Sa
// Bhupali's grammar: climb S R G P D S', descent S' D P G R S, fingerprint S R G R S D. S R G
let rules = {
  "S":  { R: 4, "D.": 3 },
  "R":  { G: 4, S: 3 },
  "G":  { P: 1, R: 4 },
  "P":  { D: 1, G: 1 },
  "D":  { "S'": 1, P: 1 },
  "S'": { D: 1 },
  "D.": { S: 3 },
};
let note = 'S', osc, drone;

function setup() {
  createCanvas(400, 400); textAlign(CENTER, CENTER); textSize(120);
  osc = new p5.Oscillator('triangle'); osc.amp(0); osc.start();
  drone = new p5.Oscillator('sawtooth'); drone.freq(sa); drone.amp(0); drone.start();
}
function mousePressed() { userStartAudio(); drone.amp(0.05, 0.5); }

function pick(row) {                       // a weighted coin toss over the row
  let total = 0; for (let k in row) total += row[k];
  let r = random(total);
  for (let k in row) { r -= row[k]; if (r < 0) return k; }
}

function draw() {
  background(244, 239, 230);
  if (frameCount % 30 === 0) {
    note = pick(rules[note]);              // the only line that changed
    osc.freq(sa * ratio[note]);
    osc.amp(0.3, 0.02);
  }
  if (frameCount % 30 === 22) osc.amp(0, 0.1);
  fill(21); text(note, width / 2, height / 2);
}

Change a number in rules and you have changed the raga's character without changing its notes. Set every number to 1 and it is a scale again.

step 08The performance

Headphones out. Volume up. Silent switch off. Open this on your phone and tap to join. Nothing plays until the conductor asks. Then: drone when told, sing when told, slow or fast when told, pads if you want to play by hand, and Sa means stop.

Every phone is tuned to the same Sa and knows the same raga, but each one sings its own line. Two hundred voices in one raga, none of them the same. That is what a mehfil is.
