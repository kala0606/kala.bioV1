01

Where it points

The code opens your repository's front page, where the README introduces the identity and the system. That page has to be ready before the code is printed.

  • Use the full repository address, for example https://github.com/[account]/[repository]. Don't use a link shortener: free short links can expire or track visitors.
  • Make the repository public and open the address in a private browser window to check it works without signing in.
  • Read the README on a phone. That's how almost every visitor will see it. See the README template.
02

Make the code

Paste your repository address. The code is drawn in your browser; nothing is sent anywhere.

Error correction level M, with a four-module quiet border.

Use the SVG for print: it stays sharp at any size. Prefer to make it with code? Ask Codex: "Make an SVG QR code for [address] with error correction M and a quiet zone of four modules, using a well-known library."

Waiting for an address.

03

Print it

Size

At least 3 cm

Square, for scanning from about arm's length. Bigger if visitors will stand further back.

Contrast

Black on white

Dark modules on a light ground. No colour inversions, gradients or logos in the middle.

Border

Keep the margin

Don't crop the white border around the code; scanners need it.

Print on matte paper or card: gloss reflects the exhibition lights straight into the phone's camera.

05

The workflow

Documentation runs in one direction, from the work to the wall. Do it in this order so nothing on the label points to something unfinished.

  1. Photograph the work.

    Following the shot list, into docs/photos/.

  2. Finish the documents.

    process.md, final-statement.md, reflection.md, and the README with its parameter table.

  3. Put a photograph at the top of the README.

    Visitors scanning the code should see the work they're standing in front of.

  4. Push, and check it as a stranger.

    Private browser window, on a phone.

  5. Make and test the QR code.

    Above.

  6. Print the card, label and code together.

    From the card builder, at 100% scale.
