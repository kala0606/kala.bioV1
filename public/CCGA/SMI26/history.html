A history you can run.

Generative art is older than the computer and newer than yesterday. Five chapters, from a rice-flour kolam to a token on a blockchain. Every master gets a program you can edit. The drawing above was made from the hash in its corner — press new hash and it will never be the same again.

How to use these pages

Each chapter has boxes like the one below. The left side is code (p5.js — the same library you will use all semester). The right side is the drawing it makes. Change a number, press run, and see what happens. Reset code brings the original back. New hash keeps your code but changes the random seed — which is exactly how a generative artwork on Art Blocks gets its 999 different outputs from one program.

Nothing you do here is saved, so break things freely. Copy anything you like into the p5.js web editor to keep it.
